Folder Structure & File Rules

To organize multiple scenes and background music for your GitHub Pages deployment:

your-repository/
├── index.html
├── bgm.mp3               <-- Background music file
└── projects/
    ├── project-1/
    │   ├── scene-1.jpg    <-- Scene 1 panorama
    │   ├── scene-2.jpg    <-- Scene 2 panorama
    │   └── scene-3.jpg
    ├── project-2/
    │   └── scene-1.jpg
    └── ... up to project-10/
  • Multiple Scenes: Name files scene-1.jpg, scene-2.jpg, etc. inside projects/project-X/.
  • Background Music: Name your audio file bgm.mp3 or music.mp3 in the root repository folder.
